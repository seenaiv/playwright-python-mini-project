# Playwright Python Automation Framework

## Overview
This is a mini automation testing framework built using Python, Playwright, and Pytest.

## Features
- Login Automation
- Add to Cart Validation
- Page Object Model (POM)
- Pytest Framework
- Reusable Fixtures

## Tech Stack
- Python
- Playwright
- Pytest

## Run Tests

**```bash
run the command in venv directory
pytest -v
```**
